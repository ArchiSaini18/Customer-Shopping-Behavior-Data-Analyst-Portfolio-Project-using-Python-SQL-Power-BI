# 👨🏻‍💻**Customer Behavior Data Analyst Portfolio Project**



Designed and developed a complete Customer Shopping Behavior Analytics solution that analyzes purchasing patterns, customer segments, product performance, and engagement trends
using Python, SQL, and Power BI to support data-driven business decisions.

🔍 **Project Overview**

This project represents a full, industry-standard end-to-end data analytics workflow, simulating the real responsibilities of a professional data analyst.
The solution covers the entire analytics lifecycle — from data ingestion and cleaning to SQL-driven analysis, dashboard development, reporting, and executive presentation.

The dashboard is designed for business stakeholders, marketing teams, and product managers to quickly understand customer behavior and identify growth opportunities.

📁 **Dataset Description**

The dataset contains transactional and behavioral customer shopping data, including:

• Customer_ID – Unique customer identifier

• Age – Customer age

• Gender – Customer gender

• Category – Product category

• Item_Purchased – Product name

• Purchase_Amount – Transaction value

• Review_Rating – Product rating

• Previous_Purchases – Purchase history

• Payment_Method – Mode of payment

• Purchase_Frequency – Shopping frequency

• Discount_Applied – Discount usage

• Location – Customer region

🎯 **Project Objectives**

The primary objectives of this project are to:

• Understand customer purchasing behavior

• Segment customers based on loyalty and engagement

• Identify top-performing products and categories

• Analyze customer ratings and satisfaction

• Support marketing, pricing, and product strategy decisions

🛠️ **Tools & Technologies**

• Python – Data loading, cleaning, and exploratory data analysis (EDA)

• Pandas & NumPy – Data manipulation and transformation

• MySQL – Data storage and analytical SQL queries

• SQLAlchemy – Python–MySQL integration

• Power BI – Dashboard design and visualization

• PowerPoint – Executive summary and presentation

• Jupyter Notebook – Analysis documentation

🔄 **Project Workflow**

1️⃣ Data Ingestion & Preparation (Python)

• Loaded raw dataset into Python

• Performed data cleaning and validation

• Handled missing values and data type corrections

• Conducted exploratory data analysis (EDA)

2️⃣ Database Integration (MySQL)

• Created MySQL database and tables

• Loaded cleaned data from Python into MySQL

• Designed queries for customer behavior analysis

3️⃣ SQL Analysis

• Customer segmentation (New, Returning, Loyal)

• Top-selling products by category

• Average product ratings and satisfaction

• Purchase frequency and spending patterns

4️⃣ Dashboard Development (Power BI)

• Built an interactive Power BI dashboard

• Created KPIs and visuals for quick insights

• Designed recruiter- and executive-friendly layout

5️⃣ Reporting & Presentation

• Generated analytical insights report

• Created a PowerPoint presentation summarizing findings

• Focused on business impact and recommendations
